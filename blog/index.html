Welcome to My Blog!

Hi, I'm John, and welcome to my blog!

I currently work in IT Support and I'm learning more about software development. I've always enjoyed working with technology, fixing problems and finding ways to make things easier.

I started this blog to share what I'm learning, the challenges I've faced and my progress as I work towards becoming a software developer.

In this blog, you'll find posts about my experiences, tutorials, and tips that I've found helpful along the way. I hope you find it useful and inspiring!

Blog Post 1: Starting My Coding Journey

Author: John Myles

Date: 5th November 2026

I've always enjoyed working with computers, but recently I decided that I wanted to learn more about how software and websites are actually built.

I started learning programming through a coding course where I was introduced to HTML, CSS and JavaScript. At first, it was a bit overwhelming because there was so much new information to take in.

As I've continued learning, things have started to make more sense. I'm still very much a beginner, but it's satisfying when I manage to get something working that I've built myself.

Blog Post 2: Learning HTML and CSS

Author: John Myles

Date: 28th October 2026

One of the first things I learned was how to create a basic website using HTML and CSS.

HTML is used to structure the content of a website, while CSS controls how everything looks. I've been practising adding headings, paragraphs, images and links to my pages.

One thing I've discovered is that even small changes can make a big difference to how a website looks. I'm looking forward to improving my skills and creating better-looking websites.

Blog Post 3: My Experience with Java

Author: John Myles

Date: 20th November 2026

As part of my learning, I've also been working with Java. This has been quite different from creating websites because it involves more programming logic.

I've been learning about variables, loops, arrays and methods. Some of the tasks have been challenging, especially when something doesn't work and I have to figure out why.

Although it can be frustrating, I enjoy the feeling of finally fixing an error and seeing my program run correctly.

Blog Post 4: Working in IT Support

Author: John Myles

Date: 12th December 2026

I currently work in IT Support at Children's Hearings Scotland, where I help colleagues with technical problems and make sure they can use their systems effectively.

My job involves troubleshooting issues, helping users and finding solutions to different technical problems.

One of the things I enjoy most is being able to solve a problem that someone has been struggling with. Working in IT has also helped me develop skills such as problem-solving, communication and patience.

I think these skills will be useful as I continue learning software development.
